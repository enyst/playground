## Reproduction

From the relevant revision, install with `npm ci --ignore-scripts`, then:

```sh
export PATH="$PWD/.agents/skills/verify-openhands/scripts:$PATH"
export CONTROL_OPENHANDS_BROWSER="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
export OH_VERIFY_RUN=$(control-openhands launch --new --build always --print-run)
control-openhands doctor
control-openhands onboard --skip
control-openhands browser viewport phone
control-openhands browser goto /conversations
control-openhands browser click 'testid=sidebar-mobile-menu-toggle'
control-openhands browser click 'testid=sidebar-mobile-drawer >> testid=backend-selector'
control-openhands browser click 'testid=manage-backends-menu-item'
control-openhands browser wait 'testid=manage-backends-modal'
control-openhands browser click 'testid=manage-backends-edit-Local'
control-openhands browser bbox 'testid=edit-backend-modal'
control-openhands browser screenshot --feature F25.phone --name phone-edit
control-openhands browser viewport 320x400
control-openhands browser fill 'testid=edit-backend-name' ''
control-openhands browser fill 'testid=edit-backend-host' 'not a host'
control-openhands browser focus 'testid=edit-backend-api-key'
control-openhands browser scroll 'testid=edit-backend-form' --by -600
control-openhands browser record start --feature F25.phone --name scrolling
control-openhands browser scroll 'testid=edit-backend-form' --by 600
control-openhands browser bbox 'testid=edit-backend-close'
control-openhands browser bbox 'testid=edit-backend-cancel'
control-openhands browser bbox 'testid=edit-backend-submit'
control-openhands browser record stop --gif

```

On this macOS host launch used `--min-free-mb 0` after checking free/reclaimable memory, with just one owned stack alive at a time. Use the default memory guard unless your host needs the same adjustment.
